# Harshit Pandey — Data Analyst Portfolio

A responsive, single-page portfolio website built using HTML and CSS, based on the information in Harshit Pandey's resume.

## Files
- `index.html` — the complete website. No installation or build step required.

## Preview locally
1. Download `index.html`.
2. Double-click it to open in your browser.

## Publish using GitHub Pages (beginner-friendly)
1. Sign in to https://github.com/.
2. Click the **+** icon in the top-right, then **New repository**.
3. Name the repository `harshit-pandey-portfolio` (or another available name).
4. Set it to **Public** and click **Create repository**.
5. On the repository page, choose **Add file** → **Upload files**.
6. Upload `index.html` (you may also upload this `README.md`).
7. Click **Commit changes**.
8. Open the repository's **Settings** → **Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Select branch **main** and folder **/(root)**, then click **Save**.
11. Wait a minute or two. The Pages section will show the website URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/harshit-pandey-portfolio/`

## Important personalization before publishing
- Check that your phone number and email are the ones you want public. The website uses the email from the resume; it intentionally does not display the phone number.
- Confirm all project descriptions match what you actually built.
- Add GitHub repository links, notebook links, Power BI screenshots, dataset sources, and verified findings when ready.
- Do not invent metrics or claim tools/skills you cannot explain in an interview.
- You can edit the text in `index.html` with Notepad, VS Code, or GitHub's web editor.

## Updating the website on GitHub
Open the repository, click `index.html`, click the pencil/edit icon, make changes, then click **Commit changes**. GitHub Pages republishes the site automatically after a short delay.
